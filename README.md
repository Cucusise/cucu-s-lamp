# cucu’s lamp

## Description

**cucu’s lamp** is a custom-designed lamp that blends functional lighting with a playful and expressive 3D-printed form. The project aims to transform a simple everyday object into something more personal and decorative, exploring how light, shape, and material interact to create atmosphere.

The lamp is built using standard, easily accessible components such as an E27 socket and bulb, combined with custom 3D-printed parts. This approach keeps the project simple and affordable while allowing a high level of customization. The design focuses on clean geometry and balanced proportions, making it suitable for different environments such as desks, shelves, or bedside tables.

By leveraging 3D printing, the lamp can be easily modified, scaled, or reinterpreted. Colors, materials, and finishes can be changed to adapt the lamp to different styles or moods, encouraging experimentation and personalization.

This project is something I had wanted to do for a long time. I created it as a way to learn and improve my 3D design skills while also pushing myself to explore a more artistic side of my work. Designing a lamp felt like the perfect balance between technical design and creative expression: it needs to be functional and practical, but it also leaves room for personality and visual character.

Throughout the process, I focused on understanding the complete workflow of creating a physical object, from the initial idea and digital modeling to 3D printing and final assembly. The project allowed me to experiment with form, proportions, and how light behaves when filtered or reflected by a 3D-printed structure. Ultimately, **cucu’s lamp** represents a personal learning journey that combines product design, digital fabrication, and artistic exploration into a single, tangible object.
